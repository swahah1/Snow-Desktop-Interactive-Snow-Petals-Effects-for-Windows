# Snow Desktop

**Snow Desktop** is a free, interactive desktop effects application for Windows that transforms your ordinary desktop into a dynamic winter environment.

The application creates realistic animated snowfall directly over your desktop and open windows, with snowflakes accumulating on window edges and at the bottom of the screen.

But it doesn't stop at snow!

&#x20;**Features**

- **Animated Snowfall:** Real-time snow particles falling across your desktop.
- **Accumulating Snow:** Snow gradually builds up on the edges of open windows and at the bottom of the screen.
- **Falling Petals:** Switch from snow to beautiful animated pink petals.
- **Adjustable Weather:** Customize particle quantity and wind direction and intensity.
- **Interactive Snow Sculpting:** Draw directly on your desktop using virtual snow.
- **Snowman Creator:** Place snowmen anywhere on your screen.
- **Snowball Throwing:** Throw virtual snowballs at open windows and watch them create temporary snow splashes.
- **Eraser Tool:** Remove individual snow sculptures.
- **Undo System:** Undo your previous sculpting actions.
- **Pause and Clear:** Pause the animations or instantly remove all accumulated effects.
- **Lightweight Interface:** A simple control panel that lets you customize everything.

### How It Works

Neve Desktop uses Windows Forms, C#, PowerShell and Windows APIs to render transparent animated overlays above the desktop and interact with visible application windows.

The application runs locally on Windows and does not require an internet connection.

### Project Goal

My goal is to create a fun, lightweight and completely free desktop experience that makes Windows feel more alive through interactive seasonal effects.

**100% free. No subscriptions. Just a little magic on your desktop.**

### &#x20;Compatibility

- Windows
- `.bat` executable launcher
- No separate installation required (PowerShell and .NET Framework components are used by the script)
